# Privacy Policy – WHOOP Claude

WHOOP Claude is a personal application created for private use to access and analyze the application owner's WHOOP data.

Data obtained through the WHOOP API may include recovery, sleep, workout, cycle, profile, and body measurement information.

The application does not sell or share WHOOP data with third parties. Data is accessed solely for personal analysis through the owner's local integration.

Access to WHOOP data is authorized through WHOOP's OAuth authentication system.

Users may revoke access to their WHOOP data at any time through their WHOOP account.
